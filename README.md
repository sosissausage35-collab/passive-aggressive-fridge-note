One funny passive-aggressive note from a smart fridge to its owner: a single dry, petty line about three days of staring into the fridge hoping the leftovers will change their mind. It is 124 characters long, within the 1–200 character gate.

## Run it

```sh
node main.ts
```

This prints the note and writes it to `/output/entry.txt`.
